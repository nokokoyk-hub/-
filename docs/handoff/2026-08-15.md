## 注意点（ハマりポイント）

### このリポジトリ固有

- **このリポは公開（public）**。配布（raw URL への curl）がそれを前提にしているので、
  **非公開に戻すと配布が静かに死ぬ**。非公開化の話が出たら必ず配布方式の変更とセットで
- 環境は「デフォルト」1個のみ。環境を増やしたら、そのセットアップスクリプトにも curl の1行が必要
- `docs/ai_handoff.md` はこのリポには存在しない（固定ハンドオフ未整備）。必要になったら作る

### Obsidian / AI開発脳まわり（今回追加）

- 🚨 **リポジトリ名は `Obsidian-Vault-`（末尾にハイフン）。** `Obsidian-Vault` では見つからない。
  ちゃぴが繋ぐときは `add_repo` に正確な名前を渡す
- 🚨 **旧 Vault（OneDrive 配下）は凍結中。** 読み取り・書き込み・検索いずれもしない。
  ここに新情報を書くと、正本が二重化して旧フォルダを消せなくなる
- **`.obsidian/plugins/` を `.gitignore` に入れてはいけない。** untrack すると pull 時に
  working tree から削除され、のんの Obsidian Git プラグイン自体が消える
- **Vault 側のコミットは Obsidian Git が自動で作る**（`vault backup: 日時` というメッセージ）。
  ちゃぴが Vault に push するときは、先に `git fetch` + `reset --hard origin/main` で
  のん側の自動コミットを取り込んでから作業する
- 同期時に大量に出る `warning: LF will be replaced by CRLF` は**無視してよい**。
  止めるべきは `error:` と `fatal:`

### のんへの接し方（今回の実感）
