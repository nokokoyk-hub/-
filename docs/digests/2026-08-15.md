## 決めたこと

| 決定 | 理由 |
|---|---|
| `.obsidian/workspace.json` は同期対象外にする | タブを動かすたびに書き換わり、10分ごとの自動同期でゴミコミットが量産されるため |
| `.obsidian/plugins/` は追跡したまま残す | untrack すると pull 時に working tree から消え、プラグイン本体が壊れるため |
| Vault を GitHub に上げるのは Clone ではなく Add local repository | Clone は GitHub→PC の向き。PC にしか無いものは上げられない |
| Codex のパス変更は GitHub 連携より先に済ませる | 後回しにするほど旧フォルダに新情報が溜まり、退避用フォルダが消せなくなる |

## 発生したエラーと解決方法

### ① `This folder contains files. Git can only clone to empty folders.`

- **原因**：そもそも Clone を使おうとしていた（向きが逆）。クローン先フォルダも既に存在していた
- **対処**：Clone をやめ、**File → Add local repository** に切り替えた
- **教訓**：PC にしか無いものを GitHub へ上げるときは Clone ではない

### ② 「Add repository」ボタンが押せない

- **原因**：そのフォルダがまだ Git リポジトリでないため（正常な挙動）
- **対処**：赤字の中の **「create a repository」リンク**を押す
- **教訓**：ボタンが押せない＝壊れている、ではない

### ③ 入れ子リポジトリ（マトリョーシカ）

- **症状**：Create 後、Changes に `.gitattributes` 1件しか出ない
- **原因**：`Create a New Repository` の **Local path ＋ Name ＝ 作成先**という仕様を説明しないまま
  「Name をハイフンに直して」と案内したため、`Obsidian Vault\Obsidian Vault` ができた
- **対処**：正しい組み合わせ（Local path=`C:\Users\nokok` / Name=`Obsidian Vault`）で作り直し
- **さらに後日談**：残骸フォルダが Vault 内に残っており、自動同期時に
  `error: 'Obsidian Vault/' does not have a commit checked out` / `fatal: adding files failed` で停止。
  内側フォルダをデスクトップへ**移動**（削除ではなく退避）して解決

### ④ コマンドパレットに Git のコマンドが出ない

- **原因**：Git for Windows が未導入。GitHub Desktop 内蔵の git は他アプリから見えない
- **対処**：Git for Windows を導入（PATH は「3rd-party software」を選択）→ Obsidian を完全再起動
- **教訓**：事前に「たぶんこれが必要になる」と予告しておくと、エラーが出ても事故に見えない

### ⑤ プラグイン「Obsidian Git」が見つからない

- **原因**：**プラグイン名と作者名が改名されていた**（Obsidian Git／Vinzent03 → **Git／Vinzent**）
- **対処**：ちゃぴの知識（2026-05まで）で断定せず Web で実地確認してから案内
- **教訓**：のんの「無くなってた」は事実だった。推測で否定せず調べる
